# Руководство администратора — Lead Manager

Документ описывает, как правильно создавать пользователей, команды и выдавать права в системе.

---

## 1. Основные понятия

| Понятие | Что это |
|---------|---------|
| **Команда (Team)** | Рабочая группа. Лиды одной команды не видны другой (кроме владельца). |
| **Пользователь (User)** | Человек, который входит в систему. Привязан максимум к одной команде. |
| **Способность (Capability)** | Роль. Один человек может иметь несколько ролей одновременно. |
| **access_revoked** | Флаг «доступ отозван». Даже если пароль правильный — войти нельзя. |

### Доступные роли (Capability)

| Роль | Код | Для кого | Что может |
|------|-----|----------|-----------|
| Владелец | `owner` | Вы / главный админ | Видит все команды, полный доступ |
| Руководитель команды | `team_manager` | Старший менеджер | Управляет своей командой |
| Оператор | `operator` | Тот, кто звонит | Работает с лидами, пишет историю звонков |
| Продажи | `sales` | Менеджер по КП | Отправляет коммерческие предложения |
| Outreach | `outreach` | Холодный обзвон / рассылка | Работа с холодными лидами |
| Сборщик данных | `collector` | Тот, кто наполняет базу | Импорт / правка сырых лидов |

> Важно: роли **комбинируются**. Можно выдать человеку и `operator`, и `sales` одновременно.

---

## 2. Как создать команду

1. Зайдите в админку: `http://127.0.0.1:8000/admin/`
2. Раздел **Accounts → Teams → Добавить**
3. Заполните:
   - **Название команды** — например `Команда Тетяни`
   - **Описание** — по желанию
4. Сохраните.

---

## 3. Как правильно создать пользователя

### Шаг 1. Создать пользователя

1. Админка → **Accounts → Users → Добавить**
2. Заполните обязательные поля:
   - **Username** — логин (латиницей, без пробелов)
   - **Password** — пароль (два раза)
3. Дополнительно рекомендуется заполнить:
   - **First name** / **Last name** — имя и фамилия (отображается в интерфейсе)
   - **Email**
   - **Team** — выберите команду, к которой относится человек
   - **Telegram ID** — если будет работать с ботом
   - **Description** — можно указать телефон менеджера (пригодится для подписи в КП)
4. Поставьте галочку **Staff status** (иначе не пустит в кабинет менеджера)
5. **Superuser status** — только себе / главному админу
6. Сохраните.

### Шаг 2. Выдать роли (Capabilities)

1. После сохранения пользователя откройте его снова.
2. Внизу найдите блок **User capabilities** → **Добавить ещё один User capability**
3. Выберите нужную роль (например `operator` или `sales`)
4. Можно добавить несколько ролей — просто нажмите «Добавить ещё один» ещё раз.
5. Сохраните пользователя.

### Пример: создание менеджера Татьяны

```
Username:          tatyana
First name:        Тетяна
Last name:         (по желанию)
Team:              Команда Тетяни
Staff status:      ✅
Capabilities:
  - operator
  - sales
Description:       тел. +380XXXXXXXXX
```

---

## 4. Как отозвать доступ

Не нужно удалять пользователя.

1. Откройте пользователя в админке.
2. Поставьте галочку **Access revoked**.
3. Сохраните.

После этого человек больше не сможет войти, даже зная пароль.

Чтобы вернуть доступ — просто снимите галочку.

---

## 5. Частые ошибки

| Ошибка | Что происходит | Как исправить |
|--------|----------------|---------------|
| Не поставили **Staff status** | Пользователь не попадает в кабинет менеджера | Поставить галочку Staff |
| Не выдали ни одной Capability | Система может ограничивать доступ | Добавить хотя бы `operator` или `sales` |
| Не выбрали **Team** | Менеджер не увидит лиды своей команды | Указать команду |
| Создали пользователя через `createsuperuser` | У него нет команды и ролей | Зайти в админку и дозаполнить |

---

## 6. Первый запуск (чеклист)

После `python manage.py migrate`:

1. Создать суперпользователя:
   ```bash
   python manage.py createsuperuser
   ```
2. Зайти в админку.
3. Создать хотя бы одну **Team**.
4. Создать пользователей-менеджеров и выдать им:
   - Staff status
   - Team
   - Capability `operator` + `sales`
5. Себе выдать Capability `owner`.
