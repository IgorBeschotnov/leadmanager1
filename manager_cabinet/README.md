# Кабінет менеджера (Django)

Готові views + шаблони під опис з `СИСТЕМА_КАК_ЕСТЬ.md` + моделі `accounts` / `leads`.

## Що є

| URL | Опис |
|-----|------|
| `/manager/tasks/` | Задачі (letter_sent + не відправлено) |
| `/manager/reports/` | Звіти по операторах + стрічка дзвінків |
| `/manager/database/` | База (все крім new/refusal/success) |
| `/manager/partners/` | Партнери (stage=success) |
| `/manager/templates/` | Список шаблонів КП + модалка |
| `/manager/lead/<id>/` | Картка ліда + генерація тексту з шаблону + копіювання + запис в історію |
| `/manager/operators/` | Список операторів |
| `/manager/operator/<id>/` | Картка оператора |

## Підключення

1. Поклади папку `manager_cabinet` як app або просто скопіюй файли в існуючий app (наприклад `manager`).

2. В `settings.py`:
```python
INSTALLED_APPS = [
    ...
    "manager_cabinet",  # або як назвеш
]

TEMPLATES = [{
    ...
    "DIRS": [],
    "APP_DIRS": True,
    ...
}]
```

3. В кореневому `urls.py`:
```python
path("manager/", include("manager_cabinet.urls")),
```

4. Переконайся, що імпорти в `views.py` відповідають твоїм app-ам:
   - `from leads.models import Company, CallLog`
   - `from accounts.models import User`

5. Статика не потрібна — Bootstrap 5 і Icons підключаються з CDN. Усе адаптивне (mobile-first).

## Логіка шаблонів КП

- Файл `letter_templates.py` містить 3 шаблони з плейсхолдерами.
- На сторінці **Шаблони** можна переглянути і скопіювати «сирий» текст.
- На **Картці ліда** кнопка шаблону підставляє реальні дані компанії + ім’я поточного користувача, показує готовий текст, дозволяє:
  - скопіювати в буфер (вставити в Telegram/Viber/WhatsApp/Email)
  - одним кліком додати цей текст у `CallLog` (історія ліда)

## Мобільна версія

- Sidebar ховається за гамбургером.
- Нижня навігація (bottom nav) на екранах < 992px.
- Таблиці з `table-responsive`, зайві колонки ховаються через `d-none d-md-table-cell`.
- Картки та кнопки зручні для пальця.

## Що вже додано

- **Фільтрація по команді** — owner бачить усе, інші тільки свою команду (+ сирі ліди без team).
- **Файли attachments/** — список файлів з папки показується в картці ліда; можна відмітити які прикріпили при «КП відправлено» (імена пишуться в історію).
- Шаблони КП з генерацією тексту + копіювання + запис в історію.
- Повна мобільна версія (sidebar + bottom nav).

## Що ще можна доробити пізніше

- Повноцінний CRUD шаблонів (зараз шаблони в `letter_templates.py`).
- Реальне скачування/відправка файлів (зараз тільки фіксація імен).
- Масове «відмітити відправленим».
- Завантаження нових файлів через веб-форму.
